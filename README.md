## 💻 Tech Stack & Experience Architecture

* **Frontend Framework:** React 18 + Vite 5
* **3D Visual Engine:** Three.js (Procedural WebGL architectural monolith with dynamic floor plates, gold wireframe lighting, and volumetric ambient particles)
* **Motion & Scrubbing:** GSAP + ScrollTrigger (Pinned dual-phase hero sequence with momentum damping)
* **Audio Synthesis:** Web Audio API (In-browser spatial low-frequency drone synthesizer)
* **Styling:** Custom Haute Architectural CSS Design System (Zero horizontal overflow, full mobile & touch optimization, responsive typography)

## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* npm (v9+)

### Installation
```bash
# Clone the repository
git clone git@github.com:Tejasree-ats/mkms-builders.git
cd mkms-builders

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```

Visit `http://localhost:5173` to preview the interactive experience.

### Production Build
```bash
npm run build
npm run preview
```
